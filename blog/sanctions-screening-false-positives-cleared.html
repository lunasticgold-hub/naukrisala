AML & KYC

How sanctions screening flags names, and how false positives get cleared

1 min read

Sanctions screening compares customer names against lists of sanctioned people and entities. Matching is fuzzy, because spellings vary across languages and documents. That is why a common name can flag even when the customer has no connection to the listed person. A flag is the start of an investigation, not a conclusion.

Clearing a false positive properly

  • Compare date of birth, nationality, and place of birth first. One solid mismatch on these fields usually clears the alert.
  • Check identifiers such as passport or national ID numbers where the list provides them.
  • Look at the full name structure, including middle names and name order, which vary by culture.
  • Write down exactly which fields matched and which did not, so the next reviewer sees the reasoning.

Never clear an alert because the name is common. Clear it because the evidence shows a different person. That distinction is the whole job.
