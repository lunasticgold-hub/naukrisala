Data Science & AI

From spreadsheet work to a data analyst role

1 min read

People who work in spreadsheets all day already do analysis: filtering, looking up values, summarising with pivot tables, and presenting findings. The move into a data analyst role builds on that foundation rather than replacing it. What changes is scale, tools, and repeatability: queries replace manual steps, and dashboards replace one-off sheets.

The bridge in order

  • Learn SQL until you can reproduce your common spreadsheet reports as queries, which proves the transfer directly.
  • Add one visualisation tool and rebuild a real report in it, keeping the same numbers so the comparison is honest.
  • Learn basic statistics: averages, distributions, and why an average alone can mislead.
  • Document one analysis end to end, from question to conclusion, as portfolio evidence.

When describing spreadsheet work in interviews, talk about decisions the analysis changed, not about the size of the files.
